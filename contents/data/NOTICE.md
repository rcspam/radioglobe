# Third-party data

`countries.json` is derived from Natural Earth's 1:110m Admin 0 Countries
data (public domain). Source: https://www.naturalearthdata.com/

Station listings come from the community-run Radio Browser directory
(https://www.radio-browser.info/), dedicated to the public domain.

`Globe.qml` and `RadioModel.js` are adapted from Radio Atlas by Akshar Patel
(MIT, https://github.com/AksharP5/omarchy-radio-atlas).
